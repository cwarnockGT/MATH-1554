    Problem 2.1.1.

    (8 points) Suppose \(A\) is an \(m \times n\) matrix and \(\vec b\in \mathbb R ^{m}\) unless otherwise stated. Select true if the statement is true for all choices of \(A\) and \(\vec b\text{.}\) Otherwise, select false.
    🔗

    (a)

    True   /   False:   If \(\Span\left\{\vec v_1, \vec v_2, \vec v_3\right\} = \R^2\text{,}\) then \(\vec v_3 \in \Span\left\{\vec v_1, \vec v_2\right\}\text{.}\)
    🔗
    Hint.
    Think about whether \(\Span\left\{\vec v_1, \vec v_2, \vec v_3\right\} = \R^2\) implies that the vectors are linearly dependent. If they are linearly dependent, then one of them is in the span of the other two. But which one?
    🔗
    🔗
    Solution.
    It is true that the vectors are linearly dependent, so one of them belongs in the span of the other two, but it doesn’t have to be \(\vec v_3\text{.}\)
    🔗
    Counterexample: Let \(\vec v_1 = \vec v_2 = \begin{bmatrix} 1 \\ 0 \end{bmatrix}\) and \(\vec v_3 = \begin{bmatrix} 0 \\ 1 \end{bmatrix}\text{.}\) Then \(\Span\left\{\vec v_1, \vec v_2, \vec v_3\right\} = \R^2\text{,}\) but it is not the case that \(\vec v_3 \in \Span\left\{\vec v_1, \vec v_2\right\}\text{.}\) Instead we have that \(\vec v_2 \in \Span\left\{\vec v_1, \vec v_3\right\}\text{.}\)
    🔗
    🔗
    🔗

    (b)

    True   /   False:   If \(A\) is an \(m \times n\) matrix with a pivot in every column, then the linear transformation \(T(\vec x) = A\vec x\) is onto.
    🔗
    Answer.
    False.
    🔗
    🔗
    Solution.
    The hypothesis guarantees that \(T(\vec x) = A\vec x\) is one-to-one, not onto.
    🔗
    Counterexample: Let \(A = \begin{bmatrix} 1 \\ 0 \end{bmatrix}\text{.}\) Then, \(A\) has a pivot in every column, but the transformation \(T\begin{pmatrix} x_1 \end{pmatrix} = A\begin{pmatrix} x_1 \end{pmatrix} = \begin{bmatrix} x_1 \\ 0 \end{bmatrix}\) is not an onto linear transformation.
    🔗
    🔗
    🔗

    (c)

    True   /   False:   The set of vectors in \(\mathbb{R}^3\) that satisfy \(-5x_1+ 3x_2 + x_3 = 0\) is a plane in \(\mathbb{R}^3\text{.}\)
    🔗
    Answer.
    True.
    🔗
    🔗
    Solution.
    This is a homogeneous system of one equation in three unknowns that can be represented with the matrix \(A = \begin{bmatrix} -5 \amp 3 \amp 1\end{bmatrix}\text{.}\) Since there are two free variables, the solution set is 2-dimensional, so a plane.
    🔗
    🔗
    🔗

    (d)

    True   /   False:   If \(A\) is an \(n \times n\) matrix, then the equation \(A\vec x = \vec b\) is always consistent.
    🔗
    Answer.
    False.
    🔗
    🔗
    Solution.
    This can only be true if \(A\) has a pivot in every row, which is not guaranteed by the hypothesis.
    🔗
    Counterexample: Let \(A = \begin{bmatrix} 1 \amp 1 \\ 0 \amp 0 \end{bmatrix}\text{.}\) Note that the system \(A\vec x = \begin{bmatrix} 0 \\ 1 \end{bmatrix}\) has no solution.
    🔗
    🔗
    🔗

    (e)

    True   /   False:   If \(A\vec{x}=\vec{b}\) has at least two distinct solutions, then \(A\vec{x}=\vec{0}\) has a nontrivial solution.
    🔗
    Answer.
    True.
    🔗
    🔗
    Solution.
    Since \(A\vec x = \vec b\) has more than one solution, it must have infinitely many. Therefore, \(A\) has a free variable. So, there must be a nontrivial solution to \(A\vec x = \vec 0\text{.}\)
    🔗
    You can see this directly by letting \(\vec v_1\) and \(\vec v_2\) be two distinct solutions to \(A\vec x = \vec b\text{.}\) Then we have that \(\vec v_1 - \vec v_2 \neq \vec 0\) and
    \begin{equation*} A(\vec v_1 - \vec v_2) = A\vec v_1 - A\vec v_2 = \vec b - \vec b = \vec 0\text{.} \end{equation*}
    Thus, \(\vec v_1 - \vec v_2\) is a nontrivial solution to \(A\vec x = \vec 0\text{.}\)
    🔗
    🔗
    🔗

    (f)

    True   /   False:   If \(T:\R^n \rightarrow \R^m\) is a one-to-one linear transformation and \(\vec u,\vec v \in\mathbb{R}^n\) such that \(T(\vec u - \vec v) = \vec 0\text{,}\) then \(\vec u = \vec v\text{.}\)
    🔗
    Answer.
    True.
    🔗
    🔗
    Solution.
    Approach 1: Since \(T\) is one-to-one, we know that the only solution to \(T(\vec x) = \vec 0\) is \(\vec x = \vec 0\text{.}\) Since \(\vec u - \vec v\) is a solution to \(T(\vec x) = \vec 0\text{,}\) we must have that \(\vec u - \vec v = \vec 0\) which implies that \(\vec u = \vec v\text{.}\)
    🔗
    Apporach 2: Since \(T\) is a linear transformation and since \(T(\vec u - \vec v) = \vec 0\text{,}\) we see that \(T(\vec u) - T(\vec v) = \vec 0\) which implies that \(T(\vec u) = T(\vec v)\text{.}\) Since \(T\) is one-to-one, we have by the function definition of one-to-one that if two outputs are equal, then their inputs must be equal. Therefore, \(\vec u = \vec v\text{.}\)
    🔗
    🔗
    🔗

    (g)

    True   /   False:   If \(A\) and \(B\) are \(2\times 3\) matrices with the same number of pivots, then \(A\) and \(B\) are row equivalent.
    🔗
    Answer.
    False.
    🔗
    🔗
    Solution.
    Row equivalent matrices do have the same number of pivots, but these pivots must occur in the same columns.
    🔗
    Counterexample: Let \(A = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 1 \amp 0 \end{bmatrix}\) and \(B = \begin{bmatrix} 1 \amp 0 \amp 0 \\ 0 \amp 0 \amp 1 \end{bmatrix}\text{.}\) Note that \(A\) and \(B\) both have 2 pivots, but they are not row equivalent since the pivots occur in different columns.
    🔗
    🔗
    🔗

    (h)

    True   /   False:   If \(A\vec{x}=\vec{b}\) has at most one solution for every \(\vec{b}\in\mathbb{R}^m\text{,}\) then the columns of \(A\) are linearly independent.
    🔗
    Answer.
    True.
    🔗
    🔗
    Solution.
    If \(A\vec x = \vec b\) has at most one solution for every \(\vec{b}\in\mathbb{R}^m\text{,}\) then we know that the only solution to \(A\vec x = \vec 0\) is the trivial solution. Therefore, \(A\) has a pivot in every column. Thus, the columns of \(A\) must be linearly independent.
    🔗
    🔗
    🔗
    🔗

    Problem 2.1.2.

    (4 points) Indicate whether the following situations are possible or impossible.
    🔗

    (a)

    Possible   /   Impossible:   A system of linear equations with exactly two solutions.
    🔗
    Answer.
    Impossible.
    🔗
    🔗
    Solution.
    A system of linear equation can only have 0, 1, or infinitely many solutions, never exactly two. Suppose \(\vec v_1\) and \(\vec v_2\) are two distinct solutions to the system \(A \vec x = \vec b\text{.}\) Let \(\vec w = r\vec v_1 + (1-r)\vec v_2\) for \(r\in\R\) and note that
    \begin{equation*} A\vec w = A(r\vec v_1 + (1-r)\vec v_2) = rA\vec v_1 + (1-r)A\vec v_2 = r\vec b + (1-r)\vec b = \vec b\text{.} \end{equation*}
    So, \(\vec w\) is a solution to \(A\vec x = \vec b\text{,}\) regardless of the choice of \(r \in \R\text{.}\) Hence, having more than one solution forces infinitely many solutions.
    🔗
    🔗
    🔗

    (b)

    Possible   /   Impossible:   A linear transformation \(T: \mathbb{R}^4 \rightarrow \mathbb{R}^4\) which is one-to-one, but not onto.
    🔗
    Answer.
    Impossible.
    🔗
    🔗
    Solution.
    Since \(T\) is one-to-one, we know that the standard matrix of \(T\text{,}\) \(A\text{,}\) has a pivot in every column. Since \(A\) is a square matrix, it must also have a pivot in every row. Therefore, \(T\) is onto.
    🔗
    🔗
    🔗

    (c)

    Possible   /   Impossible:   A \(3\times 3\) matrix \(A\) such that \(A\vec{x}=\vec{0}\) has infinitely many solutions.
    🔗
    Answer.
    Possible.
    🔗
    🔗
    Solution.
    Let \(A = \begin{bmatrix} 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \\ 0 \amp 0 \amp 0 \end{bmatrix}\text{.}\) Then every vector \(\vec x \in \R^3\) is a solution to \(A\vec x = \vec 0\text{.}\)
    🔗
    🔗
    🔗

    (d)

    Possible   /   Impossible:   A matrix \(A\) and two vectors \(\vec b\) and \(\vec c\) so that both equations \(A\vec x = \vec b\) and \(A\vec x = \vec c\) have solutions, but \(A\vec x = \vec b + \vec c\) does not have a solution.
    🔗
    Answer.
    Impossible.
    🔗
    🔗
    Solution.
    Let \(\vec v\) be a solution to \(A\vec x = \vec b\) and let \(\vec u\) be a solution to \(A\vec x = \vec v\text{.}\) Then we have that
    \begin{equation*} A(\vec v + u) = A\vec v + A\vec u = \vec b + \vec c\text{.} \end{equation*}
    Thus, the equation \(A\vec x = \vec b + \vec c\) must have a solution.
    🔗
    🔗
    🔗
    🔗
    🔗

    Problem 2.1.3.

    (2 points) Let \(A\) be an \(m \times n\) matrix. Which statement below is equivalent to “the columns of \(A\) are linearly independent”? Select only one.
    🔗
    1. \(A\vec{x}=\vec{b}\) is consistent for every \(\vec{b}\text{.}\)
      🔗
    2. \(A\vec{x}=\vec{0}\) has only the trivial solution.
      🔗
    3. \(A\) has a pivot in every row.
      🔗
    4. The columns of \(A\) span \(\mathbb{R}^m\text{.}\)
      🔗
    Answer.
    Option (b) is correct.
    🔗
    🔗
    Solution.
    Option (a) is not correct. Note the matrix \(A = \begin{bmatrix} 1 \\ 1 \end{bmatrix}\) has linearly independent columns, but it is not the case that \(A\vec x = \vec b \) is consistent for every \(\vec b \in \R^2\text{.}\)
    🔗
    Option (b) is correct. If the columns of \(A\) are linearly independent, then we know that \(A\) doesn’t have any free variables. So, there can only be the trivial solution to \(A\vec x = \vec 0\)
    🔗
    Option (c) is not correct. The same counterexample from Option (a) gives a matrix that has linearly independent columns, but it does not have a pivot in every row.
    🔗
    Option (d) is not correct. The same counterexample from Option (a) gives a matrix that has linearly independent columns, but the columns do not span \(\R^m\text{.}\)
    🔗
    🔗
    🔗

    Problem 2.1.4.

    (4 points) Let
    \begin{equation*} A=\begin{bmatrix} 1 \amp 0 \amp 2 \amp \rvert \amp 1\\ 0 \amp 2 \amp 4 \amp \rvert \amp 0\\ 0 \amp 0 \amp 2 \amp \rvert \amp 1 \end{bmatrix} \end{equation*}
    Which of the following statements are true? Select all that apply.
    1. \(A\) is in echelon form (REF).
      🔗
    2. \(A\) is in reduced row echelon form (RREF).
      🔗
    3. \(A\) is an augmented matrix of a linear system with 3 equations and 4 variables.
      🔗
    4. \(A\) is an augmented matrix of a consistent linear system.
      🔗
    🔗
    Answer.
    Options (a) and (d) are correct.
    🔗
    🔗
    Solution.
    Option (a) is correct since \(A\) has its nonzero leading entries in each row to the left of the nonzero leading entries of the rows below them AND all rows of zeros are at the bottom (there are none) AND there are zeros below each pivot position.
    🔗
    Option (b) is not correct since there are not 1’s in the pivot positions.
    🔗
    Option (c) is not correct since the system only has three variables because there are only three columns to the left of the augmentation line.
    🔗
    Option (d) is correct since we are in REF and we do not have a row of the form \(\begin{bmatrix} 0 \amp \dots \amp 0 \amp \rvert \amp a \end{bmatrix}\text{,}\) where \(a \neq 0\text{.}\)
    🔗
    🔗
    🔗

    Problem 2.1.5.

    (2 points) Consider the linear system in variables \(x_1,x_2,x_3\) with unknown constants below.
    \begin{equation*} \begin{array}{llr} a_1 x_1 + a_2 x_2 + a_3 x_3 \amp=\amp b_1\\ a_1 x_1 + a_2 x_2 + a_3 x_3 \amp= \amp -b_1 \end{array} \end{equation*}
    Which of the following statements about the solution set are possible? Select all that apply.
    1. The solution set is empty.
      🔗
    2. The solution set is a single point.
      🔗
    3. The solution set is a line.
      🔗
    4. The solution set is a plane.
      🔗
    🔗
    Answer.
    Options (a) and (d) are possible.
    🔗
    🔗
    Solution.
    Option (a) is possible. Let \(a_1 = a_2 = a_3 = 0\) and let \(b_1 = 1\text{.}\)
    🔗
    Option (b) is not possible. Notice that
    \begin{equation*} \begin{bmatrix} a_1 \amp a_2 \amp a_3 \amp \rvert \amp b_1 \\ a_1 \amp a_2 \amp a_3 \amp \rvert \amp -b_1 \end{bmatrix} \sim \begin{bmatrix} a_1 \amp a_2 \amp a_3 \amp \rvert \amp b_1 \\ 0 \amp 0 \amp 0 \amp \rvert \amp -2b_1 \end{bmatrix}\text{.} \end{equation*}
    Thus, the system has at least two free variables. Therefore, there is no way to get a unique solution.
    🔗
    Option (c) is not possible. Notice that the system has at least two free variables. Therefore, there is no way to get a line’s worth of solutions, which requires exactly one free variable.
    🔗
    Option (d) is possible. Let \(a_1 = a_1 = a_3 = 1\) and \(b_1 = 0\text{.}\)
    🔗
    🔗
    🔗

    Problem 2.1.6.

    (3 points) Let \(T: \mathbb{R}^2 \rightarrow \mathbb{R}^2\) be the linear transformation which first reflects vectors about \(x_1 = x_2\text{,}\) and then rotates vectors 90\(^\circ\) clockwise about the origin. Determine the matrix \(A\) so that \(T(\vec x)=A\vec x\) for all \(\vec x \in \mathbb{R}^2\text{.}\)
    🔗
    \begin{equation*} A = \framebox{$\phantom{$\begin{bmatrix} a \amp a \amp a \amp a \amp a \\ b \\ c \\d \\ d \\ d \end{bmatrix}$}$ } \end{equation*}
    🔗
    Answer.
    \(A = \begin{bmatrix} 1 \amp 0 \\ 0 \amp -1 \end{bmatrix}\)
    🔗
    🔗
    Solution.
    Recall that \(A = \begin{bmatrix} T(\vec e_1) \amp T(vec e_2)\end{bmatrix}\text{.}\)
    🔗
    For \(T(\vec e_1)\text{,}\) first note that reflecting the vector \(\vec e_1 = \begin{bmatrix} 1 \\ 0 \end{bmatrix}\) about the line \(x_1 = x_2\) results in the vector \(\begin{bmatrix} 0 \\ 1 \end{bmatrix}\text{.}\) Then, rotating this vector \(90^\circ\) clockwise about the origin yields the vector \(\begin{bmatrix} 1 \\ 0 \end{bmatrix}\text{.}\) (If you have a hard time seeing this, draw a picture.) Therefore, we have that \(T(\vec e_1) = \begin{bmatrix} 1 \\ 0 \end{bmatrix}\text{.}\)
    🔗
    For \(T(\vec e_2)\text{,}\) first note that reflecting the vector \(\vec e_2 = \begin{bmatrix} 0 \\ 1 \end{bmatrix}\) about the line \(x_1 = x_2\) results in the vector \(\begin{bmatrix} 1 \\ 0 \end{bmatrix}\text{.}\) Then, rotating this vector \(90^\circ\) clockwise about the origin yields the vector \(\begin{bmatrix} 0 \\ -1 \end{bmatrix}\text{.}\) (If you have a hard time seeing this, draw a picture.) Therefore, we have that \(T(\vec e_2) = \begin{bmatrix} 0 \\ -1 \end{bmatrix}\text{.}\)
    🔗
    It follows that \(A = \begin{bmatrix} T(\vec e_1) \amp T(\vec e_2) \end{bmatrix} = \begin{bmatrix} 1 \amp 0 \\ 0 \amp -1 \end{bmatrix}\text{.}\)
    🔗
    🔗

    Problem 2.1.7.

    (3 points) List the values of \(h\) that make the vectors below linearly dependent. If no value of \(h\) makes the vectors linearly dependent, write DNE in the blank. If every value of \(h\) makes the vectors linearly dependent, write \(\R\) in the blank.
    \begin{equation*} \vec v_1=\begin{bmatrix}1\\-2\\1\end{bmatrix},\quad \vec v_2=\begin{bmatrix}3\\h\\-1\end{bmatrix},\quad \vec v_3=\begin{bmatrix}2\\-4\\2\end{bmatrix} \end{equation*}
    🔗
    \begin{equation*} h = \framebox{$\phantom{$\begin{bmatrix} a \amp a \amp a \\ a \end{bmatrix}$}$ } \end{equation*}
    🔗
    Answer.
    All values of \(h\) make the vectors dependent, so \(h = \R\text{.}\)
    🔗
    🔗
    Solution.
    Note that
    \begin{equation*} A = \begin{bmatrix} \vec v_1 \amp \vec v_2 \amp \vec v_3 \end{bmatrix} = \begin{bmatrix} 1 \amp 3 \amp 2 \\ -2 \amp h \amp -4 \\ 1 \amp -1 \amp 2 \end{bmatrix} \sim \begin{bmatrix} 1 \amp 3 \amp 2 \\ 0 \amp h+6 \amp 0 \\ 0 \amp -4 \amp 0 \end{bmatrix}\text{.} \end{equation*}
    It follows that the third column of \(A\) corresponds to a free variable regardless of the choice of \(h\text{.}\) This is because \(\vec v_3 = 2\vec v_1\text{.}\) Therefore, every value of \(h\) would make the three vectors linearly dependent. Hence, \(h = \R\text{.}\)
    🔗
    🔗
    🔗

    Problem 2.1.8.

    (3 points) Find the values of \(a, b, c\) so that \(\vec x=\begin{pmatrix}1\\-1\\2\end{pmatrix}\) is a solution to \(A\vec x = \vec b\text{.}\)
    \begin{equation*} A=\begin{pmatrix} 2 \amp 0 \amp a \\ 4 \amp b \amp 1 \\ -2 \amp 5 \amp 4 \end{pmatrix}, \quad \vec b = \begin{pmatrix} 4 \\ 3 \\ c \end{pmatrix} \end{equation*}
    🔗
    \begin{equation*} a = \framebox{$\phantom{$\begin{bmatrix} a \amp a \\ a \end{bmatrix}$}$ } \qquad b = \framebox{$\phantom{$\begin{bmatrix} a \amp a \\ a \end{bmatrix}$}$ } \qquad c = \framebox{$\phantom{$\begin{bmatrix} a \amp a \\ a \end{bmatrix}$}$ } \end{equation*}
    🔗
    Answer.
    We have \(a = 1\text{,}\) \(b = 3\text{,}\) and \(c = 1\text{.}\)
    🔗
    🔗
    Solution.
    Note that
    \begin{equation*} A\vec x = \vec b \implies \begin{bmatrix} 2 \amp 0 \amp a \\ 4 \amp c \amp 1 \\ -2 \amp 5 \amp 4 \end{bmatrix}\begin{bmatrix} 1 \\ -1 \\ 2 \end{bmatrix} = \begin{bmatrix} 4 \\ 3 \\ c \end{bmatrix} \implies \begin{bmatrix}2 + 2a \\ 6 - b \\ 1 \end{bmatrix} = \begin{bmatrix} 4 \\ 3 \\ c \end{bmatrix}. \end{equation*}
    Setting corresponding entries equal, we find that \(a = 1, b = 3\) and \(c = 1\text{.}\)
    🔗
    🔗

    Problem 2.1.9.

    (4 points) Suppose \(A=\begin{bmatrix} 2 \amp -1 \\ -4 \amp 2\end{bmatrix}\text{.}\) Sketch (a) a vector \(\vec b\) such that \(A\vec x=\vec b\) is consistent, and (b) the set of solutions to \(A\vec x=\vec 0\text{.}\)
    🔗
    Answer.
    Correct for (a) is a vector drawn in \(\Span\left\{\begin{bmatrix} 1 \\ -2 \end{bmatrix}\right\}\text{.}\) Correct for (b) is the entire line \(\Span\left\{\begin{bmatrix} 1 \\ 2 \end{bmatrix}\right\}\text{.}\)
    🔗
    🔗

    Be sure to draw the entire line.

    🔗
    🔗

    🔗

    (7 points) Show your work in the space below and put your answer in the boxes.
    🔗
    Let \(T\) be the linear tranformation defined by
    \begin{equation*} T\left(\begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix}\right) = \begin{bmatrix} x_1 - 2x_2 + x_3 \\ x_1 - x_2 \\ -x_2 + x_3 \end{bmatrix}\text{.} \end{equation*}

    What is the standard matrix of \(T\text{?}\)
    🔗
    \begin{equation*} \framebox{$\phantom{$\begin{bmatrix} a \amp a \amp a \amp a \\ a \\ a \\ a \\ a \end{bmatrix}$}$ } \end{equation*}
    🔗
    Answer.
    \(A = \begin{bmatrix} 1 \amp -2 \amp 1 \\ 1 \amp -1 \amp 0 \\ 0 \amp -1 \amp 1 \end{bmatrix}\)
    🔗
    🔗
    Solution.

    \begin{equation*} T\left(\begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix}\right) = \begin{bmatrix} x_1 - 2x_2 + x_3 \\ x_1 - x_2 \\ -x_2 + x_3 \end{bmatrix} = \begin{bmatrix} 1 \amp -2 \amp 1 \\ 1 \amp -1 \amp 0 \\ 0 \amp -1 \amp 1 \end{bmatrix}\begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix}\text{.} \end{equation*}

    (c)

    Find a vector \(\vec x\) such that \(T(\vec x) = \vec b\text{,}\) where \(\vec b = \begin{bmatrix} 4 \\ 2 \\ 2 \end{bmatrix}\text{.}\)
    🔗
    \begin{equation*} \vec b = \framebox{$\phantom{$\begin{bmatrix} a \amp a \\ a \\ a \\ a \\ a \end{bmatrix}$}$ } \end{equation*}
    🔗
    Answer.
    Any particular vector of the form \(\vec x = \begin{bmatrix} 0 \\ -2 \\ 0 \end{bmatrix} + t\begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}\text{,}\) where \(t\) can be any real number. For example, setting \(t = 0\text{,}\) we get \(\vec x = \begin{bmatrix} 0 \\ -2 \\ 0 \end{bmatrix}\text{.}\)
    🔗
    🔗
    Solution.
    Since \(T(\vec x) = A\vec x\text{,}\) we use row operations on the augmented matrix \(\begin{bmatrix} A \amp \rvert \amp \vec b \end{bmatrix}\) to solve the system. Note that
    \begin{equation*} \begin{bmatrix} 1 \amp -2 \amp 1 \amp \rvert \amp 4 \\ 1 \amp -1 \amp 0 \amp \rvert \amp 2 \\ 0 \amp -1 \amp 1 \amp \rvert \amp 2 \end{bmatrix} \sim \begin{bmatrix} 1 \amp 0 \amp -1 \amp \rvert \amp 0 \\ 0 \amp 1 \amp -1 \amp \rvert \amp -2 \\ 0 \amp 0 \amp 0 \amp \rvert \amp 0 \end{bmatrix}\text{.} \end{equation*}
    We have that \(x_3 = t \in \mathbb{R}\) is a free variable and \(x_2 = -2 + t\) and \(x_1 = t\text{.}\) Thus, all solutions to \(T(\vec x) = \vec b\) are
    \begin{equation*} \vec x = \begin{bmatrix} t \\ -2 + t \\ t \end{bmatrix} = \begin{bmatrix} 0 \\ -2 \\ 0 \end{bmatrix} + t\begin{bmatrix} 1 \\ 1 \\ 1 \end{bmatrix}\text{.} \end{equation*}
    Letting \(t = 0\text{,}\) we have that a particular solution is \(\vec x = \begin{bmatrix} 0 \\ -2 \\ 0 \end{bmatrix}\text{.}\)
