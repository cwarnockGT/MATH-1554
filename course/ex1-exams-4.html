    Problem 2.1.13.

    (8 points) Suppose \(A\) is an \(m \times n\) matrix and \(\vec b\in \mathbb R ^{m}\) unless otherwise stated. Select true if the statement is true for all choices of \(A\) and \(\vec b\text{.}\) Otherwise, select false.
    🔗

    (a)

    True   /   False:   If the system \(A \vec x = \vec0\) has infinitely many solutions, then the columns of \(A\) are linearly dependent.
    🔗
    Hint.
    \(A\vec x = \vec 0 \) having infinite solutions tells us something about the number of pivots and free variables that \(A \) has.
    🔗
    🔗
    Solution.
    True. If the system \(A\vec x = \vec 0\) has infinitely many solutions, then \(A \) must be at least one free variable. So the columns of \(A \) are linearly dependent.
    🔗
    🔗
    🔗

    (b)

    True   /   False:   If \(A\) has a pivot in every row, then the equation \(A \vec x = \vec b\) must have a unique solution.
    🔗
    Hint.
    Consider some non-square matrices \(A \)
    🔗
    🔗
    Solution.
    False. Consider \(A = \begin{bmatrix} 1 \amp 1 \end{bmatrix}, \vec b = \begin{bmatrix} 1 \end{bmatrix} \text{.}\) Then we have the distinct solutions \(\vec x_1 = \begin{bmatrix} 1 \\ 0 \end{bmatrix} \) and \(\vec x_2 = \begin{bmatrix} 0 \\ 1 \end{bmatrix} \text{,}\) among many others.
    🔗
    🔗
    🔗

    (c)

    True   /   False:   If \(T ( \vec x ) = A \vec x \) is a linear transformation that is both one-to-one and onto, then \(A\) must be a square matrix.
    🔗
    Hint.
    A linear transformation being one-to-one tells you something about the number of pivots in the columns of \(A\text{.}\) A linear transformation being onto tells you something about the number of pivots in the rows of \(A\text{.}\)
    🔗
    🔗
    Solution.
    True. If \(T \) is one-to-one, then \(A \) has a pivot in every column. And if \(T \) is onto, then \(A \) has a pivot in every row. The only matrices with pivots in every row and every column are square matrices.
    🔗
    🔗
    🔗

    (d)

    True   /   False:   The set of vectors in \(\mathbb{R}^3\) that satisfy \(10x_1 - 3x_2 + x_3 = 0\) is a line in \(\mathbb{R}^3\text{.}\)
    🔗
    Hint.
    Write \(10x_1 - 3x_2 + x_3 = 0 \) as a homogenous matrix equation.
    🔗
    🔗
    Solution.
    True. The set of vectors that satisfy \(10x_1 - 3x_2 + x_3 = 0 \) is the solution set of the homogeneous system \(A \vec x = \vec 0 \) where \(A = \begin{bmatrix} 10 \amp -3 \amp 1 \end{bmatrix} \text{.}\) Since \(A \) has two free variables, the solution set is a plane in \(\mathbb R^3 \text{.}\) (In particular, it is the plane \(\vec x = \Span \left\{ \begin{bmatrix} 3 \\ 10 \\ 0 \end{bmatrix}, \begin{bmatrix} -1 \\ 0 \\ 10 \end{bmatrix} \right\} \text{.}\))
    🔗
    🔗
    🔗

    (e)

    True   /   False:   If \(A, B, \) and \(C\) are \(n \times n\) matrices such that \(AC = BC\) and \(C\) is not the zero matrix, then it must be the case that \(A = B\text{.}\)
    🔗
    Hint.
    Play around with some \(2 \times 2 \) matrices.
    🔗
    🔗
    Solution.
    False. Consider \(A = \begin{bmatrix} 1 \amp 0 \\ 0 \amp 0 \end{bmatrix}, B = \begin{bmatrix} 0 \amp 0 \\ 1 \amp 0 \end{bmatrix}, C = \begin{bmatrix} 0 \amp 0 \\ 0 \amp 1 \end{bmatrix} \text{.}\) Then \(AC = BC = \begin{bmatrix} 0 \amp 0 \\ 0 \amp 0 \end{bmatrix} \text{,}\) but \(A \neq B \text{.}\)
    🔗
    🔗
    🔗

    (f)

    True   /   False:   If \(\vec{v_1}\) and \(\vec{v_2}\) are solutions to the inhomogeneous equation \(A \vec x = \vec b\text{,}\) then the vector \(\vec{v_1} + \vec{v_2}\) is not a solution to \(A \vec x = \vec b\text{.}\)
    🔗
    Hint.
    Compute \(A(\vec{v_1} + \vec{v_2})\)
    🔗
    🔗
    Solution.
    True. If \(\vec v_1 \) and \(\vec v_2 \) are solutions to the inhomogeneous equation \(A \vec x = \vec b \text{,}\) then \(A \vec v_1 = \vec b \) and \(A \vec v_2 = \vec b \text{.}\) So we have
    \begin{equation*} A(\vec{v_1} + \vec{v_2}) = A\vec{v_1} + A\vec{v_2} = \vec b + \vec b = 2\vec b \end{equation*}
    which is not equal to \(\vec b\) since \(\vec b \neq \vec 0\text{.}\)
    🔗
    🔗
    🔗

    (g)

    True   /   False:   If \(A\) is a \(3 \times 3\) matrix such that \(A \vec x = \vec b\) is consistent for every \(\vec b \in \mathbb{R}^3\text{,}\) then the columns of \(A\) are linearly independent.
    🔗
    Hint.
    If \(A \vec x = \vec b\) is consistent for every \(\vec b \in \mathbb{R}^3\text{,}\) then you know something about the pivots of \(A\text{.}\)
    🔗
    🔗
    Solution.
    True. If \(A \vec x = \vec b\) is consistent for every \(\vec b \in \mathbb{R}^3\text{,}\) then \(A\) has a pivot in every row. Since \(A\) is a square matrix, it must also have a pivot in every column. So the columns of \(A\) are linearly independent.
    🔗
    🔗
    🔗

    (h)

    True   /   False:   If \(\vec b \in \Span \{ \vec{v_1}, \vec{v_2} \}\) and \(\vec b \in \Span \{ \vec{v_2}, \vec{v_3} \}\text{,}\) then \(\vec b \in \Span \{ \vec{v_1}, \vec{v_3} \}\text{.}\)
    🔗
    Hint.
    Draw a picture in \(\R^3 \text{.}\)
    🔗
    🔗
    Solution.
    False. Consider \(\vec v_1 = \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}, \vec v_2 = \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix}, \vec v_3 = \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}, \vec b = \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix} \text{.}\) Then \(\vec b \in \Span\{\vec v_1, \vec v_2\} \) and \(\vec b \in \Span\{\vec v_2, \vec v_3\} \text{,}\) but \(\vec b \notin \Span\{\vec v_1, \vec v_3\} \text{.}\)
    🔗
    🔗
    🔗
    🔗

    Problem 2.1.14.

    (4 points) Indicate whether the following situations are possible or impossible.
    🔗

    (a)

    Possible   /   Impossible:   Four linearly independent vectors in \(\mathbb{R}^3\text{.}\)
    🔗
    Hint.
    Consider the columns of a \(3 \times 4 \) matrix.
    🔗
    🔗
    Solution.
    Impossible. Any \(3 \times 4 \) matrix has at most 3 pivots, so the columns of any \(3 \times 4 \) matrix are linearly dependent. So there cannot be four linearly independent vectors in \(\R^3 \text{.}\)
    🔗
    🔗
    🔗

    (b)

    Possible   /   Impossible:   A linear transformation \(T\) such that \(\vec{v_1}\) and \(\vec{v_2}\) are linearly independent, but \(T(\vec{v_1})\) and \(T(\vec{v_2})\) are linearly dependent.
    🔗
    Hint.
    Linear transformations can be thought of as matrices. Consider some different matrices.
    🔗
    🔗
    Solution.
    Possible. One example is the linear transformation \(T \) that sends every vector to the zero vector.
    🔗
    🔗
    🔗

    (c)

    Possible   /   Impossible:   A one-to-one linear transformation \(T(\vec{x}) = A \vec{x}\) such that the homogeneous system \(A \vec{x} = \vec{0}\) has non-trivial solutions.
    🔗
    Hint.
    Play around with some different matrices \(A\text{.}\)
    🔗
    🔗
    Solution.
    Impossible. A one-to-one linear transformation sends different vectors to different vectors. So if \(A \vec{x} = \vec{0}\) has a non-trivial solution, then there is a non-zero vector \(\vec{v}\) such that \(A \vec{v} = \vec{0}\text{.}\) But since \(A \vec{0} = \vec{0}\text{,}\) this would imply \(\vec{v} = \vec{0}\text{,}\) which is a contradiction.
    🔗
    🔗
    🔗

    (d)

    Possible   /   Impossible:   A \(2 \times 3\) matrix \(A\) and a vector \(\vec{b} \in \mathbb{R}^2\) so that the solutions set of \(A \vec{x} = \vec{b}\) is a single point.
    🔗
    Hint.
    Consider the number of possible pivots in \(A\text{.}\)
    🔗
    🔗
    Solution.
    Impossible. A \(2 \times 3 \) matrix can have at most 2 pivots, so the solution set of \(A \vec x = \vec b \) must have at least one free variable. So the solution set cannot be a single point.
    🔗
    🔗
    🔗
    🔗
    🔗

    Problem 2.1.15.

    (2 points) Let \(A \vec{x} = \vec{b}\) be a consistent inhomogeneous linear system where
    \begin{equation*} A=\begin{bmatrix} 2 \amp 2 \amp 1 \amp 3\\ -1 \amp 0 \amp 4 \amp 1\\ 5 \amp 3 \amp 1 \amp 1 \end{bmatrix} \end{equation*}
    \(\textit{Select all that apply}\)
    🔗
    1. \(A\vec{x}=\vec{0}\) has the only trivial solution.
      🔗
    2. \(\vec{x} \in \mathbb{R}^4\) and \(\vec{b} \in \mathbb{R}^3\text{.}\)
      🔗
    3. The solution set of the system \(A \vec{x} = \vec{b}\) is parallel to the solution set of the homogeneous system \(A \vec{x} = \vec{0}\)
      🔗
    4. If \(\vec{p}\) is a solution of \(A\vec{x} = \vec{b}\text{,}\) then \(\vec{w} = \vec{p} + \vec{v}_h\) is the general solution of \(A \vec{x} = \vec{b} \) where \(\vec{v}_h\) is any solution of \(A \vec{x} = \vec{0}\)
      🔗
    Solution.
    Options (b), (c), and (d) are correct.
    🔗
    Option (a) is not correct. \(A \) is a \(3 \times 4 \) matrix, so it must have at least one free variable. So the homogeneous system \(A \vec x = \vec 0 \) has a non-trivial solution.
    🔗
    Option (b) is correct. Since \(A \) is a \(3 \times 4 \) matrix, the vector \(\vec x \) must be in \(\R^4 \) (i.e a \(4 \times 1 \) matrix) and therefore the vector \(\vec b \) must be in \(\R^3 \text{.}\)
    🔗
    Option (c) is correct because Option (d) is correct (the \(\vec p \) vector describes the translation)
    🔗
    Option (d) is correct. This is exactly Theorem 6 from Section 1.5 of Lay 5th Edition.

    Problem 2.1.16.

    (2 points) Let \(A\) be a \(3 \times 3\) matrix that has linearly dependent columns. Which of the following are true? \(\textit{Select all that apply}\)
    1. \(A\vec{x} = \vec{b}\) is consistent for every \(\vec{b}\) in \(\mathbb{R}^3\text{.}\)
      🔗
    2. the RREF of \(A\) has a zero row.
      🔗
    3. the columns of \(A\) span \(\mathbb{R^3}\text{.}\)
      🔗
    4. the system \(A \vec{x} = \vec{0}\) has a free variable
      🔗
    🔗
    Solution.
    Options (b) and (d) are correct.
    🔗
    Option (a) is not correct. Since \(A\) has linearly dependent columns, it is missing a pivot in at least one column. But because \(A \) is square, it cannot have a pivot in every row, which means that \(A\vec{x} = \vec{b}\) is not consistent for every \(\vec{b} \in \mathbb{R}^3\text{.}\)
    🔗
    Option (b) is correct. As above, \(A \) is missing a pivot in at least one row, which means that it must have a zero row in its RREF.
    🔗
    Option (c) is not correct. \(A \) has at most two linearly independent columns, so the columns of \(A \) cannot span \(\R^3 \text{.}\)
    🔗
    Option (d) is correct. As before, \(A \) is missing a pivot in at least one column, which means that \(A \) has at least one free variable.
    🔗

    Problem 2.1.17.

    (3 points) Fill in the missing entries so that the vector \(\vec{v} = \begin{pmatrix} 1 \\ 2 \\ 0 \end{pmatrix}\) is a solution to the system
    \begin{equation*} 2x_1 + \framebox{$\phantom{$\begin{bmatrix} \amp a \\ a \end{bmatrix}$}$ } x_2 - x_3 = 2 \end{equation*}
    \begin{equation*} \framebox{$\phantom{$\begin{bmatrix} \amp a \\ a \end{bmatrix}$}$ } x_1 - 2x_2 = -1 \end{equation*}
    \begin{equation*} 4x_1 + 2x_3 = \framebox{$\phantom{$\begin{bmatrix} \amp a \\ a \end{bmatrix}$}$ } \end{equation*}
    🔗
    Solution.
    We have the following system of equations:
    \begin{equation*} 2x_1 + A x_2 - x_3 = 2 \end{equation*}
    \begin{equation*} B x_1 - 2x_2 = -1 \end{equation*}
    \begin{equation*} 4x_1 + 2x_3 = C \end{equation*}
    And we know that \(\vec{v} = \begin{pmatrix} 1 \\ 2 \\ 0 \end{pmatrix}\) is a solution to this system. That is, we have
    \begin{equation*} 2(1) + A(2) - (0) = 2 \end{equation*}
    \begin{equation*} B(1) - 2(2) = -1 \end{equation*}
    \begin{equation*} 4(1) + 2(0) = C \end{equation*}
    🔗
    Solving these equations, we find that \(A = 0\text{,}\) \(B = 3\text{,}\) and \(C = 4\text{.}\)
    🔗
    🔗
    🔗

    Problem 2.1.18.

    (3 points) Consider the following system of linear equations.
    🔗
    \begin{equation*} x_1 + 2x_2 + 3x_3 = 7 \end{equation*}
    \begin{equation*} -2x_2 - 4x_3 = -6 \end{equation*}
    \begin{equation*} x_1 + 2x_2 + 5x_3 = 11 \end{equation*}
    Suppose the system is written in matrix form as \(A\vec{x} = \vec{b}\text{.}\) Express \(\vec{b}\) as a linear combination of the columns of \(A\text{.}\)
    🔗
    \begin{equation*} \begin{pmatrix} 7 \\ -6 \\ 11 \end{pmatrix} = \framebox{$\phantom{$\begin{bmatrix} a \end{bmatrix}$}$ } \begin{pmatrix} 1 \\ 0 \\ 1 \end{pmatrix} + \framebox{$\phantom{$\begin{bmatrix} a \end{bmatrix}$}$ } \begin{pmatrix} 2 \\ -2 \\ 2 \end{pmatrix} + \framebox{$\phantom{$\begin{bmatrix} a \end{bmatrix}$}$ } \begin{pmatrix} 3 \\ -4 \\ 5 \end{pmatrix} \end{equation*}
    Solution.
    Expressing the system of equations in augmented matrix form, we have
    🔗
    \begin{align*} \begin{bmatrix} 1 \amp 2 \amp 3 \amp \rvert \amp 7 \\ 0 \amp -2 \amp -4 \amp \rvert \amp -6 \\ 1 \amp 2 \amp 5 \amp \rvert \amp 11\end{bmatrix}\\ \overset{R_3 - R_1 \to R_3}{\large \sim} \begin{bmatrix} 1 \amp 2 \amp 3 \amp \rvert \amp 7 \\ 0 \amp -2 \amp -4 \amp \rvert \amp -6 \\ 0 \amp 0 \amp 2 \amp \rvert \amp 4\end{bmatrix}\\ \overset{R_2/(-2) \to R_2}{\underset{R_3/2 \to \R_3}{\large \sim}} \begin{bmatrix} 1 \amp 2 \amp 3 \amp \rvert \amp 7 \\ 0 \amp 1 \amp 2 \amp \rvert \amp 3 \\ 0 \amp 0 \amp 1 \amp \rvert \amp 2\end{bmatrix}\\ \overset{R_1 - 3R_3 \to R_1}{\underset{R_2 - 2R_3 \to R_2}{\large \sim}} \begin{bmatrix} 1 \amp 2 \amp 0 \amp \rvert \amp 1 \\ 0 \amp 1 \amp 0 \amp \rvert \amp -1 \\ 0 \amp 0 \amp 1 \amp \rvert \amp 2\end{bmatrix}\\ \overset{R_1 - 2R_2 \to R_1}{\large \sim} \begin{bmatrix} 1 \amp 0 \amp 0 \amp \rvert \amp 3 \\ 0 \amp 1 \amp 0 \amp \rvert \amp -1 \\ 0 \amp 0 \amp 1 \amp \rvert \amp 2\end{bmatrix} \end{align*}
    🔗
    and so the solution is \(\vec{x} = \begin{pmatrix} 3 \\ -1 \\ 2 \end{pmatrix}\text{.}\) Rewriting as a vector equation, we obtain
    \begin{equation*} \begin{pmatrix} 7 \\ -6 \\ 11 \end{pmatrix} = 3 \begin{pmatrix} 1 \\ 0 \\ 1 \end{pmatrix} + (-1) \begin{pmatrix} 2 \\ -2 \\ 2 \end{pmatrix} + 2 \begin{pmatrix} 3 \\ -4 \\ 5 \end{pmatrix} \end{equation*}
    🔗
    🔗

    Problem 2.1.19.

    (4 points) Let \(A = \begin{bmatrix} 1 \amp 1 \\ 2 \amp 3 \end{bmatrix}\) and \(B = \begin{bmatrix} 0 \amp b \\ 2 \amp d \end{bmatrix}\text{.}\) Find \(b\) and \(d\) so that \(AB = BA\)
    🔗
    \begin{gather*} b = \framebox{$\phantom{$\begin{bmatrix} a \end{bmatrix}$}$ }\\ d = \framebox{$\phantom{$\begin{bmatrix} a \end{bmatrix}$}$ } \end{gather*}
    🔗
    🔗
    Solution.
    Computing \(AB\) and \(BA\text{,}\) we have
    \begin{equation*} AB = \begin{bmatrix} 1 \amp 1 \\ 2 \amp 3 \end{bmatrix} \begin{bmatrix} 0 \amp b \\ 2 \amp d \end{bmatrix} = \begin{bmatrix} 2 \amp b + d \\ 6 \amp 2b + 3d \end{bmatrix} \end{equation*}
    \begin{equation*} BA = \begin{bmatrix} 0 \amp b \\ 2 \amp d \end{bmatrix} \begin{bmatrix} 1 \amp 1 \\ 2 \amp 3 \end{bmatrix} = \begin{bmatrix} 2b \amp 3b \\ 2 + 2d \amp 2 + 3d \end{bmatrix} \end{equation*}
    🔗
    Notice that if we want \(AB = BA\text{,}\) then we must have \(2 = 2b \) (the matrices must agree in the first row, first column), and \(6 = 2 + 2d \) (the matrices must agree in the second row, second column). Solving these equations, we find that \(b = 1\) and \(d = 2\text{.}\)
    🔗

    Problem 2.1.21.

    (2 points) Fill in the blank so that the systems with the two augmented matrices below have the same solution set.
    \begin{equation*} \begin{bmatrix} 1 \amp 2 \amp \rvert \amp 1 \\ -2 \amp -3 \amp \rvert \amp -3 \end{bmatrix} \end{equation*}
    and
    \begin{equation*} \begin{bmatrix} 1 \amp 2 \amp \rvert \amp 1 \\ 2 \amp 5 \amp \rvert \amp \framebox{$\phantom{$\begin{bmatrix} a \end{bmatrix}$}$ }\end{bmatrix} \end{equation*}
    🔗
    Solution.
    The missing entry is \(1 \text{.}\)
    🔗
    \begin{equation*} \begin{bmatrix} 1 \amp 2 \amp \rvert \amp 1 \\ -2 \amp -3 \amp \rvert \amp -3 \end{bmatrix} \overset{R_2 + 4R_1 \to R_2}{\sim} \begin{bmatrix} 1 \amp 2 \amp \rvert \amp 1 \\ 2 \amp 5 \amp \rvert \amp 1 \end{bmatrix} \end{equation*}

    Problem 2.1.22.

    (7 points) Show your work for part (c) in the space below and put your hint in the boxes.
    🔗
    Let \(T\) be the linear transformation defined by
    \begin{equation*} T \begin{pmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} \end{pmatrix} = \begin{bmatrix} x_1 - x_3 \\ 2x_1 + x_2 + x_3 \end{bmatrix} \end{equation*}
    🔗

    (a)

    What are the domain and codomain of \(T\text{?}\)
    🔗
    🔗
    \begin{align*} \text{Domain is } \framebox{$\phantom{$\begin{bmatrix} a \amp a \\ a \amp a \end{bmatrix}$}$ }\\ \text{Codomain is }\framebox{$\phantom{$\begin{bmatrix} a \amp a \\ a \amp a \end{bmatrix}$}$ } \end{align*}
    🔗
    Solution.
    \(T \) takes in vectors with three components and outputs vectors with two components. So the domain is \(\mathbb{R}^3\) and the codomain is \(\mathbb{R}^2\text{.}\)
    🔗
    🔗
    🔗

    (b)

    Find the matrix \(A\) such that \(T(\vec{x}) = A \vec{x}\) for all \(\vec{x}\text{.}\)
    🔗
    🔗
    \begin{equation*} A = \framebox{$\phantom{$\begin{bmatrix} a \amp a \amp a \\ a \amp a \amp a \\ a \amp a \amp a \end{bmatrix}$}$ } \end{equation*}
    🔗
    Solution.
    Option 1: Notice that
    \begin{equation*} \begin{bmatrix} x_1 - x_3 \\ 2x_1 + x_2 + x_3 \end{bmatrix} = \begin{bmatrix} 1 \amp 0 \amp -1 \\ 2 \amp 1 \amp 1 \end{bmatrix} \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} \end{equation*}
    Therefore, the matrix \(A\) is
    \begin{equation*} A = \begin{bmatrix} 1 \amp 0 \amp -1 \\ 2 \amp 1 \amp 1 \end{bmatrix} \end{equation*}
    🔗
    Option 2: The matrix \(A\) can also be found by applying \(T\) to the standard basis vectors \(\vec{e}_1 = \begin{bmatrix} 1 \\ 0 \\ 0 \end{bmatrix}, \vec{e}_2 = \begin{bmatrix} 0 \\ 1 \\ 0 \end{bmatrix}, \vec{e}_3 = \begin{bmatrix} 0 \\ 0 \\ 1 \end{bmatrix}\) and using the results as the columns of \(A\text{.}\)
    \begin{gather*} T(\vec{e}_1) = \begin{bmatrix} 1 \\ 2 \end{bmatrix}, \quad T(\vec{e}_2) = \begin{bmatrix} 0 \\ 1 \end{bmatrix}, \quad T(\vec{e}_3) = \begin{bmatrix} -1 \\ 1 \end{bmatrix} \end{gather*}
    Therefore, the matrix \(A\) is
    \begin{equation*} A = \begin{bmatrix} 1 \amp 0 \amp -1 \\ 2 \amp 1 \amp 1 \end{bmatrix} \end{equation*}
    🔗
    🔗
    🔗

    (c)

    Find a vector \(\vec{x}\) such that \(T ( \vec{x}) = \vec{b}\) where \(\vec{b} = \begin{bmatrix}3 \\ 4 \end{bmatrix}\text{.}\)
    🔗
    🔗
    \begin{equation*} \vec{x} = \framebox{$\phantom{$\begin{bmatrix} a \amp a \\ a \amp a \\ a \amp a \\ a \amp a \end{bmatrix}$}$ } \end{equation*}
    🔗
    Solution.
    Solving the system of equations given by \(T(\vec{x}) = \vec{b}\text{,}\) or equivalently \([ \, A \mid \vec{b} \, ]\text{,}\) we get
    \begin{align*} \begin{bmatrix} 1 \amp 0 \amp -1 \amp \rvert \amp 3 \\ 2 \amp 1 \amp 1 \amp \rvert \amp 4 \end{bmatrix} \overset{R_2 - 2R_1 \to R_2}{{\large \sim}} \begin{bmatrix} 1 \amp 0 \amp -1 \amp \rvert \amp 3 \\ 0 \amp 1 \amp 3 \amp \rvert \amp -2 \end{bmatrix} \end{align*}
    🔗
    which we can now express in parametric vector form as
    \begin{equation*} \vec{x} = \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} = \begin{bmatrix} 3 + x_3 \\ -2 - 3x_3 \\ x_3 \end{bmatrix} = \begin{bmatrix} 3 \\ -2 \\ 0 \end{bmatrix} + x_3 \begin{bmatrix} 1 \\ -3 \\ 1 \end{bmatrix} \end{equation*}
    🔗
    One simple solution is obtained by setting \(x_3 = 0\text{,}\) which gives
    \begin{equation*} \vec{x} = \begin{bmatrix} 3 \\ -2 \\ 0 \end{bmatrix} \end{equation*}
    🔗
    🔗
    🔗

    (d)

    Is \(T\) one-to-one?
    🔗
    Hint.
    We have proven that a linear transformation is one-to-one if and only if there is a pivot in every column of the standard matrix of the transformation.
    🔗
    🔗
    Solution.
    No. The standard matrix of \(T\) does not have a pivot in every column, so \(T\) is not one-to-one. Another way to see this is from the answer from Part (c); there are multiple solutions to the system \(T(\vec{x}) = \vec{b}\text{,}\) which indicates that \(T\) is not one-to-one.
    🔗
    🔗
    🔗

    (e)

    Is \(T\) onto?
    🔗
    Hint.
    We have proven that a linear transformation is onto if and only if there is a pivot in every row of the standard matrix of the transformation.
    🔗
    🔗
    Solution.
    Yes. The standard matrix of \(T\) has a pivot in every row, so \(T\) is onto. Another way to see this is by solving the system \(T(\vec{x}) = \vec{b}\) for an arbitrary \(\vec{b} = \begin{bmatrix} b_1 \\ b_2 \end{bmatrix}\) and showing that a solution always exists.
    🔗

    Problem 2.1.23.

    (6 points) Show your work for problems on this page and put your answers in the boxes.
    🔗
    Find all \(h\) such that the following set of vectors is linearly dependent. For that \(h\text{,}\) find a non-trivial linear combination of the vectors that adds to zero.
    🔗
    \begin{equation*} \left\{ \begin{pmatrix}0 \\ 1 \\ 2 \end{pmatrix},\begin{pmatrix}-1 \\ 1 \\ 1\end{pmatrix},\begin{pmatrix}h \\ -1 \\ 1\end{pmatrix} \right\} \end{equation*}
    🔗
    \(h = \framebox{$\phantom{$\begin{bmatrix} a \end{bmatrix}$}$ }\)
    🔗
    \(\framebox{$\phantom{$\begin{bmatrix} a \amp a \amp a \amp a \amp a \amp a \amp a \amp a \\ a \\ a \\ a \\ a\end{bmatrix}$}$ }\)
    🔗
    Hint.
    We want the matrix \(A = \begin{bmatrix} 0 \amp -1 \amp h \\ 1 \amp 1 \amp -1 \\ 2 \amp 1 \amp 1 \end{bmatrix}\) to be missing a pivot. (Why?) Once it is missing a pivot, we want to find a nontrivial solution to \(A \vec{x} = \vec{0} \text{.}\) (Why?)
    🔗
    🔗
    Solution.
    Let \(A = \begin{bmatrix} 0 \amp -1 \amp h \\ 1 \amp 1 \amp -1 \\ 2 \amp 1 \amp 1 \end{bmatrix}\text{.}\) Row reducing, we find that
    \begin{align*} \begin{bmatrix} 0 \amp -1 \amp h \\ 1 \amp 1 \amp -1 \\ 2 \amp 1 \amp 1 \end{bmatrix} \overset{R_2 \leftrightarrow R_1}{{\large \sim}} \begin{bmatrix} 1 \amp 1 \amp -1 \\ 0 \amp -1 \amp h \\ 2 \amp 1 \amp 1 \end{bmatrix} \\ \overset{R_3 - 2R_1 \to R_3}{{\large \sim}} \begin{bmatrix} 1 \amp 1 \amp -1 \\ 0 \amp -1 \amp h \\ 0 \amp -1 \amp 3 \end{bmatrix} \\ \overset{R_2 - R_3 \to R_2}{\underset{-R_2 \to R_2}{{\large \sim}}} \begin{bmatrix} 1 \amp 1 \amp -1 \\ 0 \amp 1 \amp -h \\ 0 \amp 0 \amp 3-h \end{bmatrix} \end{align*}
    🔗
    If we want the columns of \(A\) to be linearly dependent, we need to be missing a pivot in a column. This occurs when \(3-h = 0\text{,}\) i.e., \(h = 3\text{.}\)
    🔗
    If \(h = 3\text{,}\) then we can row reduce further to find
    \begin{align*} \begin{bmatrix} 1 \amp 1 \amp -1 \\ 0 \amp 1 \amp -(3) \\ 0 \amp 0 \amp 3 - (3) \end{bmatrix} = \begin{bmatrix} 1 \amp 1 \amp -1 \\ 0 \amp 1 \amp -3 \\ 0 \amp 0 \amp 0 \end{bmatrix} \overset{R_1 - R_2 \to R_1}{{\large \sim}} \begin{bmatrix} 1 \amp 0 \amp 2 \\ 0 \amp 1 \amp -3 \\ 0 \amp 0 \amp 0 \end{bmatrix} \end{align*}
    🔗
    and writing the general solution in parametric vector form, we get
    \begin{equation*} \vec{x} = \begin{bmatrix} x_1 \\ x_2 \\ x_3 \end{bmatrix} = \begin{bmatrix} -2x_3 \\ 3x_3 \\ x_3 \end{bmatrix} = x_3 \begin{bmatrix} -2 \\ 3 \\ 1 \end{bmatrix}, x_3 \in \mathbb{R} \end{equation*}
    🔗
    We can choose any nonzero value of \(x_3\) to get a specific linear combination of the vectors that add to zero. Choosing \(x_3 = 1 \) yields one solution of
    \begin{equation*} -2 \begin{bmatrix} 0 \\ 1 \\ 2 \end{bmatrix} + 3 \begin{bmatrix} -1 \\ 1 \\ 1 \end{bmatrix} + 1 \begin{bmatrix} (3) \\ -1 \\ 1 \end{bmatrix} = \vec{0} \end{equation*}
    🔗
    🔗
    🔗

    Problem 2.1.24.

    (6 points) Show your work for part (a) in the space below and put your answers in the boxes.
    🔗
    Consider the linear system of equations \(A \vec{x} = \vec{b}\) where
    🔗
    \begin{equation*} A = \begin{bmatrix} 1 \amp -2 \amp 1 \amp 0 \\ -1 \amp 3 \amp 0 \amp -1 \end{bmatrix} \end{equation*}
    and
    \begin{equation*} \vec{b} = \begin{bmatrix}5 \\ -5 \end{bmatrix} \end{equation*}
    🔗

    (a)

    Give the general solution of the system \(A \vec{x} = \vec{b}\) in parametric vector form.
    🔗
    🔗
    \begin{equation*} \vec{x} = \framebox{$\phantom{$\begin{bmatrix} a \amp a \amp a \amp a \\ a \\ a \\ a \end{bmatrix}$}$ } \end{equation*}
    🔗
    Solution.
    Row reducing the augmented matrix \([ \, A \mid \vec{b} \, ]\) gives
    \begin{align*} \begin{bmatrix} 1 \amp -2 \amp 1 \amp 0 \amp \rvert \amp 5 \\ -1 \amp 3 \amp 0 \amp -1 \amp \rvert \amp -5 \end{bmatrix} \overset{R_1 + R_2 \to R_2}{{\large \sim}} \begin{bmatrix} 1 \amp -2 \amp 1 \amp 0 \amp \rvert \amp 5 \\ 0 \amp 1 \amp 1 \amp -1 \amp \rvert \amp 0 \end{bmatrix} \\ \overset{R_1 + 2R_2 \to R_1}{{\large \sim}} \begin{bmatrix} 1 \amp 0 \amp 3 \amp -2 \amp \rvert \amp 5 \\ 0 \amp 1 \amp 1 \amp -1 \amp \rvert \amp 0 \end{bmatrix} \end{align*}
    🔗
    which yields the solution
    \begin{gather*} \vec{x} = \begin{bmatrix} x_1 \\ x_2 \\ x_3 \\ x_4 \end{bmatrix} = \begin{bmatrix} 5 - 3x_3 + 2x_4 \\ -x_3 + x_4 \\ x_3 \\ x_4 \end{bmatrix} = \begin{bmatrix} 5 \\ 0 \\ 0 \\ 0 \end{bmatrix} + x_3 \begin{bmatrix} -3 \\ -1 \\ 1 \\ 0 \end{bmatrix} + x_4 \begin{bmatrix} 2 \\ 1 \\ 0 \\ 1 \end{bmatrix}, \; x_3,x_4 \in \R \end{gather*}
    🔗
    🔗
    🔗

    (b)

    Let \(A\) be as defined above. Write down the solution set to the homogeneous system \(A \vec{x} = \vec{0}\) as the span of some number of vectors. \(\textit{(Hint: You may use your solution from (a) above.)}\)
    🔗
    \begin{equation*} \framebox{$\phantom{$\begin{bmatrix} a \amp a \amp a \amp a \\ a \\ a \\ a \\ a \end{bmatrix}$}$ } \end{equation*}
    🔗
    Hint.
    If \(A\vec{x} = \vec{b} \) is consistent with a solution of \(\vec{x}_p\text{,}\) then the solution set of \(A\vec{x} = \vec{b} \) is given by \(\vec{x}_p + \vec{v}_h \) where \(\vec{v}_h \) is the solution set of the corresponding homogeneous system \(A\vec{x} = \vec{0} \text{.}\)
    🔗
    🔗
    Solution.
    Since the solution set to \(A\vec{x} = \vec{b} \) is
    \begin{equation*} \vec{x} = \begin{bmatrix} 5 \\ 0 \\ 0 \\ 0 \end{bmatrix} + x_3 \begin{bmatrix} -3 \\ -1 \\ 1 \\ 0 \end{bmatrix} + x_4 \begin{bmatrix} 2 \\ 1 \\ 0 \\ 1 \end{bmatrix}, \; x_3,x_4 \in \R \end{equation*}
    the solution set to \(A\vec{x} = \vec{0} \) must be
    \begin{gather*} \vec{x} = x_3 \begin{bmatrix} -3 \\ -1 \\ 1 \\ 0 \end{bmatrix} + x_4 \begin{bmatrix} 2 \\ 1 \\ 0 \\ 1 \end{bmatrix}, \; x_3,x_4 \in \R \end{gather*}
