Theorem 3.14.

For any \(n \times n\) matrices \(A\) and \(B\text{,}\) the following properties hold:
🔗
  1. \(A\) is invertible if and only if \(\operatorname{det}(A)\neq 0\text{.}\)
    🔗
  2. \(\operatorname{det}(AB)=\operatorname{det}(A)\operatorname{det}(B)\text{.}\)
    🔗
  3. \(\operatorname{det}(A)=\operatorname{det}(A^T)\text{.}\)
    🔗
